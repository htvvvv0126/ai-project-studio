# AI 项目学习台

给普通零基础用户使用的中文AI实用课程。新主线为六阶段15课必修：认识AI、沟通、核验、工具、真实项目、多步骤与Agent使用。第七阶段个人AI工作系统2课为选修；原七关22课资料问答Agent开发路线完整保留在编程拓展，不要求所有人学习Python。

“AI运用等级图”用六级能力说明会选任务、会表达、会核验、会用工具、会做项目和会管流程，每一级对应作品与验收重点。这是本课程的能力规划，不是官方评级，也不会根据完成勾选自动授予等级。

## 学习路线与旧记录

首页只推荐前六阶段必修；选修与拓展入口保留个人系统及旧开发课程。旧阶段s1—s7、课ID、题目和自查项的顺序不变；新增core1—core7采用独立ID。本地存储键ai-project-studio-v1与version 1记录结构不变，旧JSON可直接导入。旧开发课不会被算作新必修成绩，旧笔记和考试仍归属原课。

知识题自动判分，实际操作与独立完成通过自查和作品证据核验，不自动发毕业认证。无图像、语音或工具执行能力时可先做准备练习，实际能力仍标待练。网页不接入账号、后台模型或云同步。

课程原稿在dist/course-data.js；新增通用课程与分组在dist/core-course.js。运行node build.mjs合并为可直接打开的dist/index.html。verify.cjs验证核心流程、离线和各页排版；verify-curriculum.cjs验证v3旧记录、课程完整性和新路线边界。

## 选择你能使用的工具

提示词、资料核验、项目文档和方法复用可以在 DeepSeek、ChatGPT 等聊天工具中练习。支持 Skill 的执行宿主可以自动加载方法包；普通聊天工具使用手动粘贴方法文档的路径。

编程部分的 Chat Completions 示例使用通用的 `MODEL_API_KEY`、`MODEL_NAME`、`MODEL_BASE_URL` 配置，分别指向 DeepSeek 或 OpenAI 等已核实支持对应接口的服务。LangChain Agent 给出 DeepSeek 与 OpenAI 两条集成分支。使用 openai 客户端库不表示必须使用 OpenAI 服务；具体模型能力和所需参数按当前服务文档核对。

课程的程序示例需要学习者在自己的项目中实际运行。网页不收集密钥，也不代替真实 API 调用与工具执行验收。练习资料使用原创项目说明，下载文件按空行分为六段，编号与课程引用一致。

## 直接使用

用现代浏览器双击打开 `dist/index.html`。课程、概念、知识题与学习记录不依赖网络；外部官方资料需要联网。

1. 点“开始第一课”，用现有聊天工具把一段通知变成清单，追问一次，再独立换题。
2. 按步骤动手，记录成果，并逐项自查。
3. 用本关知识题和实操任务检查自己。
4. 定期点“导出记录”，得到 JSON 备份；在另一浏览器点“导入记录”恢复。

进度保存在当前浏览器的本地存储中。移动 HTML 文件、换浏览器或清除浏览器数据后，旧记录可能不可见，请先导出。网页不会自动同步学习记录。离线版与在线版的记录分别保存，可用导出、导入转移。

实操状态为学习者自查，不是教师评分。学习台没有模型聊天后端，也无需填写 API Key。课程后续阶段会指导学习者在自己的 Python 项目中配置并验证模型服务。

## 修改源码

只需 Node.js，无需安装依赖：

```text
node build.mjs
```

源文件在 `dist/index.template.html`、`dist/styles.css`、`dist/course-data.js`、`dist/app.js`。构建将它们内联进单个 `dist/index.html`。

通用课程在 `dist/core-course.js`；前置映射、首课快速任务、七阶段反馈要求与判断练习在 `dist/learning-support.js`，也会内联，无外部运行依赖。原课程/考试ID与自查索引保留。

## 验证

`verify.cjs` 记录开发机使用 Playwright + Edge 执行的浏览器验证；它引用开发机依赖路径，并非课程运行依赖。覆盖61个页面在1440/390/320宽度的横向溢出、记录恢复、复制、导入导出、测验与独立的实操状态、资料下载及 file URL 离线保存。`verify-curriculum.cjs`检查原课程和v1记录兼容；`verify-learning.cjs`检查首个作品、提交反馈、修订快照、人工复核边界、故障题和保存失败恢复，全部使用隔离浏览器中的合成测试数据。

## 成果反馈与记录备份

“保存实操记录”沿用原自查功能。“提交成果并查看反馈”会保存当次作品、过程和逐项依据；有缺口时给出本阶段补练建议，允许修改后重新提交。知识题不代替实操；自评材料齐全仍待核验，人工复核由本人填写，不是平台老师认证。所有任意作品的实际内容仍需人工检查。

新增反馈独立保存在`ai-project-studio-feedback-v1`，原`ai-project-studio-v1`及version 1字段不变。导出文件附带可选`learningFeedback`，可一起导入。导入会提示替换课程、笔记和反馈；旧文件没有新增反馈，建议先导出当前记录。在线与离线来源仍分别保存。作品仅记录文字、文件位置或摘录，不会上传文件。

课程中的 Python 示例是学习材料，网页不执行 Python，也不声称已替学生完成项目。官方 SDK、Skill 和框架接口以资源页链接的当前文档为准。
